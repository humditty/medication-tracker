# 用药助手 - 关爱老人健康

一个专为老年人设计的简单易用的用药提醒和记录系统。

## 功能特点

### 🎯 核心功能
- **用药记录**：轻松记录每日服药情况
- **语音播报**：点击即可听取当前用药状态
- **拍照识别**：支持拍摄药物照片，方便识别
- **历史记录**：查看过往用药记录，支持7/14/30天统计
- **家属监控**：家属可远程查看老人用药情况

### ♿ 无障碍设计
- **大字体**：所有文字都经过优化，适合老年人阅读
- **高对比度**：清晰的色彩对比，易于辨认
- **大按钮**：按钮尺寸加大，方便点击
- **简洁界面**：去除复杂元素，专注核心功能

### 🎨 视觉设计
- **温暖配色**：采用温暖的米黄色调，给人安全感
- **清晰层次**：信息层次分明，一目了然
- **友好图标**：配合文字使用图标，增强理解

## 技术栈

- React 18 + TypeScript
- Vite 6
- Tailwind CSS
- Zustand (状态管理)
- date-fns (日期处理)
- Lucide React (图标)

```bash

# 启动开发服务器

```

## 使用说明

### 老人端
1. 打开应用，首页显示今日日期和用药状态
2. 点击"播报今日状态"听取当前用药情况
3. 在用药列表中，点击"标记为已服用"记录服药
4. 如需添加新药物，点击"添加药物"按钮
5. 可以上传药物照片，方便后续识别

### 家属端
1. 点击顶部导航的"家属"按钮
2. 查看老人今日用药状态和完成率趋势
3. 可以点击"联系老人"拨打电话
4. 点击"发送提醒"发送用药提醒消息

## 设计理念

本应用遵循以下设计原则：

1. **简单至上**：每个操作都不超过2步
2. **视觉优先**：大字体、大按钮、高对比度
3. **语音辅助**：关键信息提供语音播报
4. **容错设计**：误操作可以轻松撤销
5. **情感关怀**：温暖的配色和友好的提示语

## 💡 反思与思考

在开发过程中，我们意识到一个重要的问题：**技术解决方案是否真的必要？**

对于老人用药提醒这个需求，也许最简单的方案反而最有效：

> **一张A4纸，列出本月的日期，让老人家每次吃药时自己打个勾。**

这种低技术方案的优势：
- ✅ **零学习成本**：不需要学习使用任何APP
- ✅ **零维护成本**：不需要充电、更新、修bug
- ✅ **即时可见**：一眼就能看到今天的服药状态
- ✅ **物理触感**：打勾的动作本身就是一种确认和记忆强化
- ✅ **可靠性**：不会因为网络、电量、系统故障而失效

当然，数字化方案也有其价值：
- 📊 数据统计和分析（完成率趋势、漏服记录）
- 👨‍👩‍👧 家属远程监控和提醒
- 🔔 自动化的定时提醒
- 📸 药物照片管理和识别

**最终建议**：根据老人的实际情况选择最合适的方案。如果老人对智能手机不熟悉，一张简单的纸质表格可能比复杂的APP更有效。技术应该服务于人，而不是让人适应技术。

## 开发说明

项目采用模块化设计：

```
│   ├── ui/             # 基础UI组件
│   ├── MedicationList.tsx    # 用药列表
│   ├── AddMedicationDialog.tsx  # 添加药物对话框
│   ├── HistoryView.tsx        # 历史记录视图
│   └── FamilyMonitor.tsx      # 家属监控面板
├── lib/                # 工具函数和状态管理
│   ├── store.ts        # Zustand状态管理
│   └── utils.ts        # 工具函数
├── App.tsx             # 主应用组件
└── index.css           # 全局样式
```
