# 用药助手 - 关爱老人健康

一个专为老年人设计的简单易用的用药提醒和记录系统。

## 功能特点

### 🎯 核心功能
- **用药记录**：轻松记录每日服药情况
- **语音播报**：点击即可听取当前用药状态
- **拍照识别**：支持拍摄药物照片，方便识别
- **历史记录**：查看过往用药记录，支持7/14/30天统计
- **家属监控**：家属可远程查看老人用药情况

### ♿ 无障碍设计
- **大字体**：所有文字都经过优化，适合老年人阅读
- **高对比度**：清晰的色彩对比，易于辨认
- **大按钮**：按钮尺寸加大，方便点击
- **简洁界面**：去除复杂元素，专注核心功能

### 🎨 视觉设计
- **温暖配色**：采用温暖的米黄色调，给人安全感
- **清晰层次**：信息层次分明，一目了然
- **友好图标**：配合文字使用图标，增强理解

## 技术栈

- React 18 + TypeScript
- Vite 6
- Tailwind CSS
- Zustand (状态管理)
- date-fns (日期处理)
- Lucide React (图标)

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用说明

### 老人端
1. 打开应用，首页显示今日日期和用药状态
2. 点击"播报今日状态"听取当前用药情况
3. 在用药列表中，点击"标记为已服用"记录服药
4. 如需添加新药物，点击"添加药物"按钮
5. 可以上传药物照片，方便后续识别

### 家属端
1. 点击顶部导航的"家属"按钮
2. 查看老人今日用药状态和完成率趋势
3. 可以点击"联系老人"拨打电话
4. 点击"发送提醒"发送用药提醒消息

## 设计理念

本应用遵循以下设计原则：

1. **简单至上**：每个操作都不超过2步
2. **视觉优先**：大字体、大按钮、高对比度
3. **语音辅助**：关键信息提供语音播报
4. **容错设计**：误操作可以轻松撤销
5. **情感关怀**：温暖的配色和友好的提示语

## 开发说明

项目采用模块化设计：

```
src/
├── components/          # React组件
│   ├── ui/             # 基础UI组件
│   ├── MedicationList.tsx    # 用药列表
│   ├── AddMedicationDialog.tsx  # 添加药物对话框
│   ├── HistoryView.tsx        # 历史记录视图
│   └── FamilyMonitor.tsx      # 家属监控面板
├── lib/                # 工具函数和状态管理
│   ├── store.ts        # Zustand状态管理
│   └── utils.ts        # 工具函数
├── App.tsx             # 主应用组件
└── index.css           # 全局样式
```
