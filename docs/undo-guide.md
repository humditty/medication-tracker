# 撤回用药记录 - 使用指南

## 🎯 功能说明

如果老人不小心点错了"已服用"或"未服用"，可以随时**撤回记录**，重新选择正确的状态。

---

## 📱 操作步骤

### 方法一：快速撤回（推荐）

```
1. 找到点错的药物
   ↓
2. 点击底部的 "点错了？撤回记录" 按钮
   ↓
3. 确认提示框中点击 "确认撤回"
   ↓
4. 完成！药物状态恢复为"待服用"
```

### 方法二：取消撤回

如果在确认前改变主意：
```
点击 "取消" 按钮
↓
保持当前记录不变
```

---

## ⚠️ 注意事项

### 什么时候可以撤回？
- ✅ 今天内的任何记录都可以撤回
- ✅ 无论"已服用"还是"未服用"都可以撤回
- ✅ 可以多次撤回和重新记录

### 撤回后会怎样？
- 🔄 药物状态变回"待服用"
- 🗑️ 之前的记录会被删除
- 📸 如果有拍照，照片也会被删除
- ⏰ 需要重新记录时间和拍照

### 不能撤回的情况
- ❌ 昨天的记录不能通过此功能撤回
- ❌ 需要在"历史记录"中手动删除旧记录

## 💡 使用场景示例

### 场景 1：误触"已服用"
```
问题：老人还没吃药，但不小心点了"拍照确认服药"

解决：
1. 看到该药物显示"已服用"状态
2. 点击"点错了？撤回记录"
3. 确认撤回
4. 重新点击"拍照确认服药"（这次真的拍了）
```

### 场景 2：选错状态
```
问题：应该点"已服用"，但点了"未服用"

解决：
1. 点击"点错了？撤回记录"
2. 确认撤回
3. 重新点击正确的按钮
```

### 场景 3：拍照拍坏了
```
问题：照片没拍清楚，想重新拍

解决：
1. 点击"点错了？撤回记录"
2. 确认撤回
3. 重新拍照确认
```

## 👨‍👩‍👧 给家属的建议

### 如何帮助老人使用

1. **首次使用时演示**
   - 故意点错一次
   - 演示如何撤回
   - 让老人练习一次

2. **放在显眼位置**
   - 告诉老人在每个药物卡片底部
   - 有大大的"点错了？撤回记录"按钮

3. **消除顾虑**
   - 告诉老人"点错了没关系，可以改"
   - 撤回不会有任何惩罚
   - 可以反复修改直到正确

4. **定期检查**
   - 在家属监控面板查看记录
   - 发现有疑问的记录，电话确认
   - 必要时让老人撤回重拍

## 🆘 常见问题

### Q: 撤回后可以再撤回吗？
A: 撤回后状态变为"待服用"，没有记录可撤回了。但可以重新记录。

### Q: 昨天的记录能撤回吗？
A: 不能通过这个功能。需要在"历史记录"页面查看，如需修改请联系技术人员。

### Q: 撤回会通知家属吗？
A: 目前不会。家属看到的是最终状态。如果频繁撤回，建议电话沟通原因。

### Q: 误撤回怎么办？
A: 撤回后立即重新记录正确的状态即可。

### Q: 老人找不到撤回按钮怎么办？
A: 
1. 按钮在每个药物卡片的底部
2. 是灰色的大按钮
3. 写着"点错了？撤回记录"
4. 可以打印操作指南贴在旁边
