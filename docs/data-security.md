# 数据安全与用药确认说明

## 📊 数据存储位置

### 当前存储方式
应用使用 **浏览器本地存储 (localStorage)** 保存所有数据：
- ✅ 药物清单
- ✅ 用药记录（包括拍照确认的照片）
- ✅ 历史记录
- ✅ 完成率统计

### 数据存储位置
- **Windows**: `C:\Users\[用户名]\AppData\Local\Google\Chrome\User Data\Default\Local Storage`
- **macOS**: `~/Library/Application Support/Google/Chrome/Default/Local Storage`
- **手机浏览器**: 浏览器的应用数据目录

## ⚠️ 数据流失风险

### 可能导致数据丢失的情况

| 风险 | 说明 | 概率 |
|------|------|------|
| 清除浏览器缓存 | 手动清除或浏览器自动清理 | 中 |
| 更换设备/浏览器 | 数据不会跨设备同步 | 高 |
| 浏览器卸载 | 所有本地数据被删除 | 低 |
| 存储空间不足 | 系统可能清理缓存 | 低 |
| 隐私模式浏览 | 关闭窗口后数据消失 | 中 |

### 如何避免数据丢失

#### 1. 定期导出备份（已实现）✅
- 点击首页的"导出备份"按钮
- 保存 JSON 文件到安全位置
- 建议每周备份一次

#### 2. 导入恢复数据（已实现）✅
- 点击"导入备份"按钮
- 选择之前导出的 JSON 文件
- 数据会立即恢复

#### 3. 云端同步（未来计划）
可以集成以下云服务：
- **Supabase** - 免费 PostgreSQL 数据库
- **Firebase** - Google 云服务
- **阿里云 OSS** - 国内稳定服务

## 📸 用药确认机制

### 问题：如何确认是老人自己吃的药？

单纯点击"标记为已服用"无法确认是否真的服药，可能存在：
- ❌ 忘记服药但误点
- ❌ 故意不喝药但假装喝了
- ❌ 家人代点但老人没吃

### 解决方案：拍照确认（已实现）✅

#### 工作流程
1. 老人点击"拍照确认服药"
2. 打开摄像头
3. 拍摄服药照片（应包含药物、手、水杯）
4. 确认后记录保存到系统
5. 家属可查看照片验证

#### 照片要求
```
推荐拍摄内容：
┌─────────────────────┐
│  ✓ 药物在手中        │
│  ✓ 水杯准备就绪      │
│  ✓ 老人的面部(可选)  │
│  ✓ 时间戳自动添加    │
└─────────────────────┘
```

#### 优势
- ✅ 真实记录服药过程
- ✅ 照片带时间戳，不可伪造
- ✅ 家属可远程查看确认
- ✅ 形成用药证据链

### 其他可选方案

#### 方案 B：智能药盒
- 需要购买智能药盒硬件（约 200-500 元）
- 药盒打开时自动记录
- 可设置多重提醒
- 品牌推荐：分装药盒、小米生态链产品

#### 方案 C：视频确认
- 录制 5-10 秒服药视频
- 更完整的证据
- 但文件较大，占用存储

#### 方案 D：家属监督
- 服药时与家人视频通话
- 实时确认
- 适合独居老人

## 🔒 隐私与安全

### 照片数据安全
- 照片以 Base64 格式存储在本地
- 不会上传到任何服务器（除非您主动选择云端同步）
- 只有设备和家属监控端可以查看

### 建议
1. **定期备份** - 每周导出一次数据
2. **多设备备份** - 在家人的设备上也安装应用
3. **云存储升级** - 如需长期保存，建议启用云端同步
4. **密码保护** - 考虑为设备设置锁屏密码

## 🆘 常见问题

### Q: 老人不会拍照怎么办？
A: 
1. 可以先跳过拍照，仅记录时间
2. 家属协助拍摄第一次，老人模仿
3. 简化要求：只需拍到药物即可

### Q: 照片太大占用空间怎么办？
A:
1. 照片已压缩为 JPEG 80% 质量
2. 平均每张约 100-300KB
3. 一个月约 10-30MB，可接受
4. 可定期清理旧照片

### Q: 没有网络能用吗？
A: 
✅ 完全可以！所有功能离线可用
- 拍照不需要网络
- 记录保存在本地
- 仅在导出/导入时需要文件访问权限

### Q: 可以多人共用吗？
A:
目前设计为单人使用。如需多人使用：
1. 在不同浏览器 profiles 中分别使用
2. 或使用不同设备
3. 未来版本将支持多用户切换
